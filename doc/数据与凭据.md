# 数据与凭据

这个目录里的多数文件属于「运行期状态」，不入库。克隆仓库后你需要自己生成。

## 本地工具（monitor.py）

| 文件 | 入库 | 说明 |
| --- | --- | --- |
| `data/cookies.json` | ✗ | 真实登录态，内含支付宝 JSESSIONID 等会话值 |
| `data/history.csv` | ✗ | 你的电量历史记录 |
| `data/last_state.json` | ✗ | 上次运行的状态（用于去重） |
| `data/room.json` | ✗ | 当前绑定的房间（含姓名与学号） |
| `data/run.log` | ✗ | 运行日志 |

首次运行时 `monitor.py` 会自动创建这些文件。

## 本机专属配置（根目录）

| 文件 | 入库 | 说明 |
| --- | --- | --- |
| `config.json` | ✗ | 本机的房间、时段、`display_name`；首次运行自动生成 |
| `config.example.json` | ✓ | 模板，字段说明写在 `_说明` 里 |

`config.json` 之所以不入库，是因为它记录的是**本机状态**而非代码：
里面的房间绑定、订阅时段都是你个人的，别人拿去没有意义；
`monitor.py` 首次运行时又会自动重建一份。把它排掉，克隆下来的人不会
一上来就订阅到你的房间。

> 早期版本还会写入 `client_id`（`os.urandom(8).hex()` 生成的机器指纹），
> 现已移除——它既不是密钥也无需跨机共享。

另注：**`docs/` 不能加进 `.gitignore`**，它要作为 GitHub Pages 的发布目录提交上去。

## 线上服务（web/）

| 文件 | 入库 | 说明 |
| --- | --- | --- |
| `web/config.json` | ✗ | 内含 `admin_token`，泄露等于后台失守 |

从模板复制：

```bash
cp web/config.example.json web/config.json
```

然后改掉 `admin_token`。

## 浏览器 profile

`.edge-profile/`（本地扫码用）与 `_sp/`（临时验证用）合计约 290 MB，
是 Edge 的完整用户数据目录，**既庞大又含登录态**，一律不入库。

## 万一不小心提交了凭据

改掉它本身（重新扫码 / 换 token）比改写 git 历史更简单也更快。
若必须清历史：

```bash
git filter-repo --invert-paths --path data/cookies.json --path web/config.json
git push --force-with-lease
```
